# jimpayne1/tap

Homebrew tap for [Crunchpad](https://github.com/jimpayne1/crunchpad), a
high-precision macOS calculator built on the SpeedCrunch engine.

```sh
brew install --cask jimpayne1/tap/crunchpad
```

Upgrades come through `brew upgrade --cask crunchpad`. The cask is updated
automatically by Crunchpad's `macos/release.sh --publish`.
